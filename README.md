# Cisco Enterprise Network – CCNA Packet Tracer Project

## Project Overview

This project demonstrates the design and configuration of a small enterprise network using Cisco Packet Tracer.

## Technologies Implemented

- VLAN 10 – HR
- VLAN 20 – IT
- VLAN 30 – Accounts
- Access & Trunk Ports
- Router-on-a-Stick
- Inter-VLAN Routing
- R1-R2 Connectivity
- Static Routing
- DHCP
- SSH
- Port Security
- Extended ACL
- EtherChannel (LACP)
- End-to-End Connectivity Testing

## Network Topology

Cisco Packet Tracer topology containing two routers, two switches and multiple PCs.

## IP Addressing

| Network | Purpose |
|---|---|
| 192.168.10.0/24 | HR |
| 192.168.20.0/24 | IT |
| 192.168.30.0/24 | Accounts |
| 192.168.110.0/24 | Remote HR |
| 192.168.120.0/24 | Remote IT |
| 10.0.0.0/30 | R1-R2 Link |

## Security

- SSH for secure remote management
- Port Security with Sticky MAC
- Extended ACL for traffic filtering

## Verification

The following were successfully tested:

- VLAN configuration
- Inter-VLAN communication
- R1-R2 connectivity
- Static routing
- DHCP address assignment
- SSH
- Port Security
- ACL
- End-to-End ping
